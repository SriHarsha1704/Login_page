#LoginPage
Login Page – HTML & CSS
This is a simple and responsive login page built using HTML and CSS. It includes user-friendly input fields, navigation links, and buttons for login and sign-up actions.

Features
Email input field

Password input field

"Forgot Password" link

Login and Sign-Up buttons

"Continue with Google" button

Clean layout with external CSS styling

Font Awesome integration for future icon use

Files Included
index.html – Main login page

login.css – External stylesheet (not included here, but linked in HTML)

How to Use
Clone or download this repository.

Ensure both index.html and login.css are in the same directory.

Open index.html in any web browser.

Modify styles in login.css to customize the appearance.

Notes
The "Forgot Password" link currently points to a local file path. Update this to a valid URL or internal page as needed.

The Google button is only a design element. Actual functionality requires integrating with Google's OAuth service.

Future Improvements
Add form validation using JavaScript

Connect to a backend for real authentication

Improve responsiveness with media queries

Replace placeholder links with functional routes
